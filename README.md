# 3337

Modular 4K-ready sewing machine simulation starter.

## What changed
- Fixed the app structure so it runs with ES modules instead of global `THREE` references.
- Added proper modular files for engine, machine, state, interactions, and fabric guide.
- Added pointer/touch-friendly wheel dragging.
- Added a visible fabric calibration overlay.
- Improved UI telemetry and responsive layout.

## Run
Open `index.html` from a local server or deploy to GitHub Pages.

## Controls
- Power button: turns the machine on and off.
- Pedal button or Space: engages powered stitching.
- Drag the wheel: spins the machine manually.
- Fabric guide button or G: show/hide calibration overlay.
